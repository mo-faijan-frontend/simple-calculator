# 🧮 Beginners Calculator

A custom-branded, highly interactive, and responsive calculator web application designed and built entirely on an Android mobile device.

## 🚀 Live Demo
Experience the live application here: [Click to View Live Project](https://mo-faijan-frontend.github.io/simple-calculator/)

## 🛠️ Tech Stack Used
* **HTML5** - Structured with custom branding layouts.
* **CSS3** - Styled with modern borders, visual hierarchies, and CSS Pseudo-classes for interactive button states.
* **JavaScript (ES6+)** - For dynamic DOM manipulation and core calculation logic.

## ✨ Unique & Core Features
* **Dual Input System:** Two dedicated input fields for clear and precise number operations.
* **Core Arithmetic Operations:** Instant buttons for Add, Subtract, Multiply, and Divide.
* **Smart Data Recycle (= Button):** A unique feature where clicking the `=` button automatically injects the calculated result back into the first input field for continuous calculations.
* **Quick Reset (Del Button):** One-click function to clear out the results instantly.
* **Advanced Mobile Responsiveness:** Custom CSS implementation ensuring the layout stays perfectly intact and functional even when switching between Portrait and Landscape mobile orientations.

## 📱 Built Entirely on Mobile
This project showcases full mobile-development capabilities, coded via **Acode** editor and deployed using Git version control inside **Termux**.
